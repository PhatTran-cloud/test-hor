# V4.1 horror workspace

Read `Code2Video/AGENTS.md` and `Code2Video/START_HERE.md` before work.
This is the dedicated horror fork requested by the user. The original D:/manim
workspace remains the V4 source/history. Use only this workspace's production
entrypoint and outputs for new horror work. Do one human-authorized step, report
concrete rule/skill use, artifacts and remaining uncertainty, then stop.

Project skills are in `.agents/skills/horror-asset-director` and
`.agents/skills/horror-audio-director`; use them with the existing director skills.
Do not revive Làng Giấy or choose a film language/cast without user direction.

Before artwork, record story-grounded character descriptions and setting/era in
the production packet. Ask the user about unresolved choices that affect the
design; do not silently invent ages or a historical period. Follow
`Code2Video/docs/HORROR_CONTRACT.md` for this brief and its approval state.
Characters intended to animate require action/view sprites (`sprite_sequence`),
not just standing portraits. Character cutouts need real alpha PNG; other assets
need PNG only when transparency is required.
