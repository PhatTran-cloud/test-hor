# Horror profile template

horror-profile-template.json is an unselected field template, not a ready plan or
approved story. Language, main/dialogue cast, style bible, research packet and
sections must be authored for the actual user brief. Null selections are intentional;
the validator rejects them rather than inventing English/default speaker/timestamps.
Read docs/HORROR_CONTRACT.md and START_HERE.md. local_tools/v4_smoke examples are
inherited contract regression fixtures, not production horror plans.

The template now follows the current 2D/OverSimplified and human-run Flow route.
It includes the production packet and scene-shot/1 skeleton; language, cast,
actual user authorization, story, worlds and assets remain unfilled. Author them
from the real brief before running an export. `physical_facts` contains drawable
approved character/setting details; full script facts stay in the packet.
See docs/OVERSIMPLIFIED_ILLUSTRATION.md for scoped asset/view/pose `shot_ids` and
single-image constraints. These fields describe image requests, not automatic
runtime playback or artwork approval.
